# Multi-diagram workspace canvas

Idea from Marcus, 2026-09-10. Saved for later; not part of the sequence prototype.

The [linked project diagrams plan](../active/linked-project-diagrams.md) defines the concrete
Sidecar → td/Recall architecture composition journey. Use that plan for project references,
cross-project connections, boundaries and performance. This broader idea retains arbitrary frames,
multiple views of one project, and mixed architecture/sequence workspaces as future exploration.

Offer a Figma-like spatial canvas containing several independently explorable diagram frames.
Frames may show different projects, or a sequence and component view of the same system side by
side. Pan between them on a visually distinct workspace background. Keep each frame's identity,
view state and boundaries clear while retaining Fractal's detail navigation inside it.

Explore how workspace pan/zoom differs from navigation within a diagram, keyboard focus enters
and leaves a frame, and selections can reveal the same component in another frame. Keep this
workspace composition separate from repository-owned model truth. No implementation authorized
as part of the current sequence prototype.
